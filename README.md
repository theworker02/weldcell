# weldcell

Weld filesystem cell paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/weldcell/

## Install / run

```bash
git clone https://github.com/theworker02/weldcell.git
cd weldcell
node src/cli.js
node --test
```
